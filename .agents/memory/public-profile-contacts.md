---
name: Public profile contacts
description: Privacy rules for optional contact methods on CareerPath profiles.
---

Keep public contact email, LinkedIn, and phone separate from the account's sign-in email. Only show contact actions when a person explicitly adds a valid value.

**Why:** Other signed-in users can view profile records, so exposing the authentication email could reveal a private address.

**How to apply:** Keep contact methods opt-in, preserve the sign-in address as private, and validate links before rendering them.
