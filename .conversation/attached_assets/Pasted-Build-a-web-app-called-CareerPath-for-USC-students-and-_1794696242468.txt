Build a web app called CareerPath for USC students and alumni.

# CONCEPT
USC alumni networking is split across several platforms (Trojan Network, Viterbi Link, Rossier Career Network, Marshall's platform), and none of them shows students HOW alumni got where they are or helps them build real relationships. CareerPath is an AI career companion that helps students:
1. DISCOVER careers if they're undecided (Explore)
2. SEE the common path Trojans took to a dream job (Path Finder)
3. KNOW the gap between where they are and that path (My Gap)
4. FIND the right alumni and peers (Connect)
5. NETWORK with AI help: drafting messages, chatting, coffee chats (Network)
6. FOLLOW UP so connections turn into relationships (Follow-ups)
AI should help the user at EVERY step.

# DESIGN
- USC colors: cardinal (#990000) primary, gold (#FFCC00) accents, white/light gray backgrounds. Clean, modern, card-based, rounded corners, generous spacing.
- Fully responsive (great on phones).
- Friendly loading states during AI calls (e.g., "Finding Trojans like you...", "Mapping the path...").
- Top nav (students): Explore, Path Finder, My Gap, Connect, Messages, My Network, Profile.
- Top nav (alumni): Requests, Messages, Upcoming Chats, Profile.
- Footer: "Demo uses sample alumni data."

# TECH
- React frontend, Node/Express backend, Replit's built-in database, Replit Auth (or simple email + password login).
- Use an LLM API for all AI features. Store the API key in Replit Secrets; call the LLM ONLY from the backend.
- LLM responses that drive UI must be structured JSON.
- If any AI call fails, show a graceful fallback, never crash.

# AI CAREER COACH (available on every page)
- A floating "Ask CareerPath AI" button opens a side chat panel.
- It knows the user's profile and the current page context (e.g., on Path Finder it knows the goal; on an alum's profile it knows that alum).
- Each page shows 2–3 suggested prompts relevant to that page, e.g., "What should I do this semester?", "How do I ask this alum for a coffee chat?", "What should I say in my follow-up?"

# 1. LANDING PAGE
- Headline: "See how Trojans got there. Find your path."
- Subtext: "Discover careers, see the steps alumni took, and build real connections with the Trojans who can help."
- Buttons: "Get started" and "Try demo" (logs into the pre-filled demo student instantly).

# 2. ONBOARDING / PROFILE (AI: resume parsing + profile tips)
- Fields: name, USC school (Marshall, Viterbi, Dornsife, Annenberg, Rossier, Cinematic Arts, Thornton, Other), major, level (Undergrad / Master's / PhD), year, clubs, internships/work experience, skills, relevant courses, interests (tag inputs).
- "Paste your resume" box: AI extracts and auto-fills all fields; user reviews and edits.
- AI profile tips: after saving, show 2–3 suggestions to strengthen the profile (e.g., "Add your project details so alumni see what you've built").
- Final question: "Do you know what career you want?"
  - Yes → enter dream role + optional dream company → Path Finder
  - Not sure yet → Explore

# 3. EXPLORE (AI: similarity matching + "why this fits you")
- Match the student to alumni with similar STARTING profiles at USC (major, school, clubs, skills, interests, courses).
- Show 5–6 cards with DIVERSE outcomes (startup founder, big tech engineer, AI hardware, product manager, research, creative/entertainment tech). Never two cards with the same type of outcome.
- Each card: name, grad year, major, current role + company, a 3–4 step journey, and an AI "Why this might fit you" line naming specific shared details.
- "Explore this path" button → opens Path Finder pre-filled with that role/company.

# 4. PATH FINDER (AI: pattern analysis across alumni timelines)
- Input: dream role + optional company.
- Find alumni whose current or past role/company matches.
- AI analyzes their year-by-year timelines and summarizes the COMMON PATH: clubs, internships, courses, skills, and WHEN (freshman → senior → first job → dream job).
- Show a short AI summary paragraph, then a vertical visual timeline. Each step shows how many matched alumni took it (e.g., "6 of 9 did a summer internship by junior year").
- Show "Based on X Trojans".

# 5. MY GAP (AI: gap analysis + action plan)
- Compare the student's profile to the common path.
- Progress indicator ("You've completed 2 of 6 common steps") and a checklist (✅ done / ⬜ not yet).
- 3 concrete, personalized next steps for THIS semester.
- Each next step has a "Help me do this" button that opens the AI Coach with that step as context.

# 6. CONNECT (AI: ranking + explanations)
- ALUMNI: top 5 ranked by fit: dream company/role first, then boost for shared club, major, school, similar background. Each card shows "Why this person", an "Open to coffee chats" badge if applicable, and buttons: View profile, Draft message, Request coffee chat.
- PEERS: current students with the same or similar goal, showing shared clubs/interests and an AI suggestion (e.g., "You're both prepping for PM interviews; practice together"). Students can message peers too.

# 7. AI MESSAGE DRAFTING
- "Draft message" opens a composer.
- Student picks a goal: Ask for advice / Request a coffee chat / Ask about their path / Ask about a referral (referral option only appears after a prior conversation with that alum).
- Student picks a tone: Short / Warm / Professional.
- AI drafts a message referencing SPECIFIC shared details (club, major, school, interests, a step in the alum's path the student admires) with one clear ask. Under 120 words, no generic flattery.
- Buttons: Regenerate, Make it shorter, Make it more personal, Edit manually, Send.

# 8. MESSAGES (chat)
- 1:1 chat: inbox list + conversation view, stored in the database, auto-refresh every few seconds so replies appear live.
- Anti-spam: a student can send only ONE first message to an alum until the alum replies.
- "AI help me reply" button suggests a response based on the conversation.
- Alumni also get "AI help me reply" (e.g., to answer quickly or decline politely).
- Report/block on every conversation.

# 9. COFFEE CHATS (AI: request note, prep brief, notes summary)
- "Request coffee chat": student picks 15 or 30 min, virtual or on campus, up to 3 times from the alum's availability, plus an AI-drafted note.
- Alum sees it in "Requests": Accept (pick a time), Suggest another time, or Decline (AI drafts a kind decline).
- On accept: appears in "Upcoming chats" for both, with "Add to calendar" (.ics download).
- BEFORE the chat: AI Prep Brief for the student: 2-line summary of the alum's path, what you have in common, 5 smart questions, and 1 thing NOT to ask (e.g., don't ask for a referral in the first chat).
- AFTER the chat: student adds quick notes (or bullet points). AI turns them into a clean summary with key advice and action items, and adds the action items to My Gap.

# 10. FOLLOW-UPS (AI drafts every follow-up)
The app tracks every connection and creates follow-up tasks automatically:
- THANK-YOU: within 24 hours after a coffee chat → AI drafts a thank-you that mentions specific advice from the student's notes.
- NO-REPLY NUDGE: if an alum hasn't replied in 7 days → AI drafts ONE polite, short nudge. Only one nudge allowed per alum.
- CHECK-IN: 4 weeks after a coffee chat → AI drafts an update showing the student acted on the advice (pulls from completed My Gap steps).
- MILESTONE UPDATE: when the student marks a milestone (e.g., "Got an internship", "Joined a club the alum recommended") → AI suggests which alumni to update and drafts a short thank-you/update for each.
- Each follow-up shows: who, why it's due, the AI draft, and buttons Send / Edit / Snooze / Skip.
- DEMO ONLY: a "Fast-forward 1 week" button on My Network that simulates time passing so follow-ups appear during the demo.

# 11. MY NETWORK (AI: weekly networking coach)
- Dashboard of every connection with status tags: Messaged / Replied / Chat scheduled / Chat done / Follow-up due.
- Sections: Follow-ups due, Upcoming chats, Waiting for reply, Relationships (people you've had chats with).
- AI weekly summary at the top: e.g., "You have 2 follow-ups due and 1 chat Thursday. Priya suggested joining a product club; you haven't yet."

# 12. ALUMNI SIDE
- Alum profile: same fields as seed data + "Open to coffee chats" toggle, topics they're happy to help with, weekly availability slots, max chats per month.
- Alumni can pause requests anytime.
- AI helps alumni: summary of who the student is before replying ("Sophomore in Viterbi, in your old hackathon club, wants to become a PM").

# 13. PRIVACY & SAFETY
- Never show emails or phone numbers; all contact goes through the app.
- Students: max 5 new first messages per day; one first message per alum until they reply; one nudge maximum.
- Report/block everywhere. Alumni fully control availability.

# 14. SEED DATA (make it realistic and detailed)
- 60 fake USC alumni with year-by-year timelines: school, major, level, grad year, clubs, internships with years, key courses, skills, first job, current role + company, open-to-chat setting, help topics, availability.
- Clusters (8–10 alumni each) with clear shared patterns but not identical paths:
  1. Product Manager at Google
  2. Investment Banking Analyst at Goldman Sachs
  3. Consultant at McKinsey
  4. Software Engineer at Apple
  5. Marketing at Disney
- Plus 10–15 varied outcomes (startup founders, NVIDIA, research scientists, game studios, nonprofits) for Explore.
- Several alumni from the SAME starting profile (e.g., CS majors in the same clubs) who ended up in very different careers.
- Mix schools: Marshall, Viterbi, Dornsife, Annenberg, plus some Rossier and Cinematic Arts. Realistic USC-style club names.
- 25 fake current students (varied, some undecided).
- DEMO STUDENT: "Alex Kim", undecided CS sophomore in Viterbi, in a hackathon club and an entrepreneurship club, one research experience. Pre-seed 1 past coffee chat with notes so follow-ups can be shown.
- DEMO ALUM (real login for live demo on a second device): "Priya Shah", Product Manager at Google, Viterbi CS '21, former hackathon club member, open to coffee chats. Make her rank highly for Alex.
- Show demo login credentials on the login page for judges.
